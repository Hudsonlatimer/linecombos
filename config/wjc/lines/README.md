# Reported World Juniors lines

Lines reported from camp, practice or games. Add `<CODE>.json`; it overrides the model projection:

```json
{
  "source": "Steven Ellis, Daily Faceoff",
  "url": "https://...",
  "reportedAt": "2026-12-20T17:30:00Z",
  "lines": [["Last1", "Last2", "Last3"]],
  "pairs": [["LastD1", "LastD2"]],
  "goalie": "LastG"
}
```

Names are surnames as written by the reporter; they're matched to the team's player pool.
